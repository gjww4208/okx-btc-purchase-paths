## 第二步：身份认证，视频认证单独算一步

实人认证和视频认证都只能在 App 端完成，网页端做不了。这两步也属于不同操作，并非同一步的两个动作；很多人做完人脸识别就以为结束了，结果进 C2C 买币发现还要录视频。

**证件认证和人脸识别**：打开 App，点首页左上角用户中心图标，点上方昵称或账号，进【身份认证】，点【立即认证】，上传证件照（身份证正反面），按页面提示完成人脸识别。

**视频认证**：入口藏在 C2C 买币里。App 首页点【买币】→【C2C 买币】→ 右下角【我的】→【视频认证】→【开始录制】。

录制时的要求是明确的：开启声音、打开摄像头、不要连接耳机。系统会自己朗读风险提示，你不需要跟着念。确认信息无误，在“嘀”声之后回答【是的】，提交资料等待审核。

卡在这一步的人，多数是戴了耳机、麦克风没开或者摄像头权限没给。审核时长官方页面没有给出统一数字，别按网上流传的“几分钟就好”去安排时间，以页面状态为准。

认证等级会影响充提币限额，官方帮助页用图片展示具体额度，页面上是什么就是什么。

## 第四步：下第一笔 C2C 订单

C2C 是点对点市场，你用本地货币向其他用户买币。欧易托管数字资产，商家确认收到你的款之后才把币放给你。因为是直接和商家交易，能用的付款方式比传统交易所多，具体到每一单，以商家支持的为准。

App 操作顺序：

1. 点【C2C 买币】→【快捷交易】→【购买】
2. 选择要买的数字资产，选 BTC
3. 输入购买金额，选支付方式
4. 点【选择委托单】，在列表里挑商家，确认后点【去下单】
5. 核对买币详情，点【获取付款详情】
6. 按商家要求的支付方式转账
7. 付款成功后回到页面点【我已支付】，等商家收款放币

网页端流程一致，区别是确认环节叫【购买详情预览】，最后一句话是“确认已转账”。

## 买完的比特币在哪？资金账户和交易账户是两回事

这是最多教程直接跳过的一步。

官方写得很清楚：成功买入一笔数字资产后（比如 USDT），这笔资产会进入你的**【资金账户】**。想用它去交易其他数字资产，必须先做“资金划转”，从资金账户划到**【交易账户】**。

App 划转路径：【资产】→【资金划转】→ 填数量 →【确认】。
网页端：【资产管理】→ 选币种 → 填数量 →【确认】。

网页端在【资产管理】→【我的资产】里能看到资金账户、交易账户、金融账户三类资产的状况。买完 BTC 找不到币，先看资金账户，别急着找客服。

有些教程会说币进了“法币账户”或“币币账户”，这是旧叫法或别的平台叫法。欧易当前页面用的是资金账户和交易账户。

## 付款和放币环节，官方点名的四个坑

这四条来自官方帮助页的注意事项原文，我按新手能执行的方式重写了一遍：

1. **只认账单，不认短信**。必须在银行 App 或者微信、支付宝的账单里确认收到商家付款，不要凭一条短信就认为钱到了。
2. **核实是不是商家实名付款**。付款方和商家对不上，联系在线客服或者点申诉。
3. **没收到钱，绝对不要点放币**。手滑点了，立刻申诉或找在线客服。
4. **收款信息以订单详情页为准**。订单页展示的收付款方式，或者 IM 窗口里卖家推送的卡片信息里的收付款方式，哪个为准看这两个，别转错。转账备注怎么填，也按订单页和商家的提示操作。

自己作为买方付款时，同样适用第 4 条：你转钱的对象和金额，只看当前这一单的订单页。订单页的收款信息只对当前这一单有效。

## 想用更便宜的价格买？先搞清限价和市价

C2C 是跟商家成交，价格由商家挂出。想按市场价格买，就得走现货市场，前提是账户里有 USDT。

现货下单在网页端是【交易】→【现货】，选交易对，比如 BTC/USDT，然后选委托方式。官方对限价委托的说明是：需要自己输入想买入或卖出的价格，等市场行情符合预期时自动成交，**这种委托不保证快速成交**；想按当时行情快速成交，可以选市价委托。

第一次买不建议一上来就挂限价单等价格回落。你可能等不到，还可能因为不熟悉下单界面填错数量。想先熟悉流程，市价单成交更快，代价是成交价随行情走。

App 端的现货入口：连续点两次首页下方【交易】，选【现货】，右上角“...”里有【教学中心】，可以看教学视频和分步教学。

## 从别的平台充币进来买，注意这几条

已经有钱包或别的平台资产的人，可以走链上充币。路径是【资产管理】→【充币】→ 选【充币币种及网络】→【下一步】→【复制地址】，然后从对方平台提币过来，达到页面要求的确认数后到账。充币时可以选充进资金账户还是交易账户。

官方列出的几个坑，每一个都会导致币不见：

- 部分币种暂不支持通过币安智能链（BSC）充值，也不支持火币生态链（HECO）
- 充币页面下方有最小充币数量限制，低于这个数量不到账
- 到账时间取决于网络矿工确认速度和接收平台要求的确认数
- 某些币种充币要填 Memo 或 Tag，不填无法到账

网络支持情况会变，实际以充币页面实时显示为准。第一次充，先小额试一笔，确认到账再转大额。

## 常见问题

**整个流程要多久？**
身份认证和视频认证都是提交资料后等待审核，官方页面没有给统一时长。真正能自己控制的是准备材料：证件拍清楚、录视频时开声音开摄像头、不戴耳机。

**能用信用卡买吗？**
欧易新手攻略里列出的收款方式是银行卡、支付宝、微信支付三种。C2C 是跟商家直接交易，具体某一单支持什么，看订单页。

**最低能买多少？**
官方没有给出统一的最低金额。下单页面会显示商家支持的限额区间，以那里为准。

**买完能提到自己的钱包吗？**
可以。提币前需要完成身份认证，提到外部地址要选对网络，网络选错资产会丢。具体步骤以提币页面的提示为准。

**为什么我网页端找不到视频认证？**
视频认证只能在 App 端做，入口在【C2C 买币】→【我的】→【视频认证】。
